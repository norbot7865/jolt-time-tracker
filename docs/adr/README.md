# Architecture decision records

ADRs capture durable decisions, not task status or implementation logs. New
records use zero-padded names such as `0001-ports-and-adapters.md`, state their
status, context, decision, consequences, and a focused safe `d2` diagram when
it clarifies an architectural boundary. Link concrete implementation deltas
from `../changes/` when useful.

No decision has been accepted in this bootstrap repository. The Phase 1 contract
bead owns the first ADRs.
