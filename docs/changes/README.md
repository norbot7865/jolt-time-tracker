# Architecture change records

Change records describe a concrete, architecture-affecting implementation delta,
using names such as `2026-08-31-add-clockify-adapter.md`. They are smaller than
ADRs: explain intent, the relevant before/after boundary or flow, verification,
and links to durable ADRs. Use safe focused fenced `d2` diagrams when a visual
explanation adds value.

The bootstrap layout does not change an implemented runtime architecture, so it
has no change record.
